# 6. Create the APIM policy fragments

[Configure-ApimPolicyFragments.ps1](./Configure-ApimPolicyFragments.ps1) uses
Azure CLI `az rest` to create or reuse these fixed fragment identifiers:

| Fragment | Source |
|---|---|
| `atlassian-user-auth` | [atlassian-user-auth.xml](./assets/atlassian-user-auth.xml) |
| `atlassian-safe-errors` | [atlassian-safe-errors.xml](./assets/atlassian-safe-errors.xml) |

The names are fixed because the API policies in prerequisite 7 reference them.
The assets are sent as `rawxml`, preserving their policy expressions and named
value references. Local validation understands the raw C# expression quoting;
the files are not rewritten or interpolated with credentials.
The shared user-auth fragment first rejects a null `context.Subscription` with
HTTP 401. This ensures an existing open product cannot bypass the subscription
key requirement for either API, before delegated user authentication runs.
APIM can reject keys before inbound policies run. The safe-error fragment
preserves HTTP 401 for `SubscriptionKeyNotFound` and `SubscriptionKeyInvalid`,
instead of converting those authentication failures into upstream HTTP 502 errors.

## Requirements

- Complete prerequisite 5 successfully for this APIM resource.
- Azure CLI installed and signed in to the saved public-cloud subscription and
  tenant. Permission to read APIM/named-value metadata and write policy fragments
  is required, for example API Management Service Contributor.
- Root environment inputs `AZURE_APIM_NAME`, `AZURE_RESOURCE_GROUP_NAME` and
  `AZURE_SUBSCRIPTION_ID`; the earlier saved resource ID, tenant and named-value
  completion flag must match. No new user environment variables are needed.
- Referenced public named values must still match the saved configuration.
  Existing secret or Key Vault-backed references are accepted without retrieving
  or comparing their contents; a warning makes this verification limit explicit.
  All references must exist uniquely in the selected APIM instance and have valid
  resource identity and secrecy metadata. Missing/ambiguous references, invalid
  metadata and changed public values stop the script before writes.
  Prerequisite 5 still manages public values only and will not overwrite secret
  or Key Vault-backed collisions.

## Run from the repository root

Preview:

```powershell
.\pre-requisites\6.Create-APIM-Fragments\Configure-ApimPolicyFragments.ps1 -WhatIf
```

Create or reuse:

```powershell
.\pre-requisites\6.Create-APIM-Fragments\Configure-ApimPolicyFragments.ps1
```

Only after reviewing differing existing contents:

```powershell
.\pre-requisites\6.Create-APIM-Fragments\Configure-ApimPolicyFragments.ps1 -UpdateExisting
```

`-ApimName`, `-ResourceGroupName` and `-SubscriptionId` override saved inputs,
but cannot bypass the earlier resource binding. `-EnvFile` selects a separate
configuration. `-AssetDirectory` selects a directory containing both named XML
files. Relative explicit paths resolve against the PowerShell working directory;
default paths do not depend on it.

Both fragments and dependencies are preflighted before any ARM writes. Matching
content is reused, differing content requires `-UpdateExisting`, and an existing
description is retained. ARM API version is pinned to `2024-05-01`.

## Saved outputs

The shared environment writer adds these under **Generated by
6.Create-APIM-Fragments**, below every input:

- `AZURE_APIM_USER_AUTH_FRAGMENT_ID`
- `AZURE_APIM_SAFE_ERRORS_FRAGMENT_ID`
- `AZURE_APIM_POLICY_FRAGMENTS_CONFIGURED`

No output placeholders belong in [.env.v1.example](../../.env.v1.example).
The completion flag is set to `false` before applying changes and to `true`
only after both fragment contents are read back and verified. Partial Azure
writes are not rolled back. A failure stops execution; fix it and rerun.
`-WhatIf` performs reads but changes neither ARM resources nor the environment.

Creating fragments does not attach policies to an API, create subscriptions,
grant user consent or configure bot authentication. Continue with prerequisite 7.

Reference: [Policy Fragment REST API](https://learn.microsoft.com/en-us/rest/api/apimanagement/policy-fragment/create-or-update).
